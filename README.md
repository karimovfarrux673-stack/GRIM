# NOVA — zamonaviy web do‘kon

O‘zbek tilidagi, mobil qurilmalarga mos demo internet-do‘kon. HTML, CSS va JavaScript’da yozilgan; build yoki npm o‘rnatish talab qilinmaydi.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki VS Code’dagi Live Server orqali ishga tushiring.

## Imkoniyatlar

- Mahsulot qidiruvi, kategoriya filtri va saralash
- Saralanganlar tugmasi
- Mahsulot miqdori, savat, yetkazib berish va jami narx hisob-kitobi
- Demo buyurtma formasi va obuna formasi
- Mobil va desktop uchun moslashuvchan dizayn

## GitHub Pages’ga chiqarish

Loyihani GitHub’dagi repository’ga `main` branch’ga yuborganingizdan so‘ng, `.github/workflows/deploy-pages.yml` saytingizni avtomatik nashr qiladi. Birinchi marta GitHub repository’da **Settings → Pages → Build and deployment → Source → GitHub Actions** ni tanlang. Deploy tugagach, manzil **Settings → Pages** bo‘limida ko‘rinadi.

## Muhim

Rasmlar va shriftlar internet orqali tashqi manbalardan yuklanadi. Buyurtma tasdiqlash hozircha demo: backend, haqiqiy buyurtma saqlash va to‘lov tizimi ulanmagan. Haqiqiy savdo uchun bu xizmatlarni ulash zarur.
